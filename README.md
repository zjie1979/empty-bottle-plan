# 空瓶计划

一个 iPhone 优先的公开 PWA，用来记录家里已经有的日用品、护肤品、清洁用品、食品、饮品和调料，按“先用完、再决定买不买”的方式推进。

## 功能

- 添加库存：名称、分类、剩余次数、位置、到期日、是否已开封。
- 今日优先：按临期、已开封和剩余量排序。
- 一次扣减或直接空瓶。
- 想买冷静清单：先记录，72 小时后再复核。
- 本周复盘：空瓶次数、忍住没买次数、操作记录。
- 本地备份恢复：数据只保存在浏览器 localStorage。

## 隐私边界

这个应用没有账号、没有服务器、不会上传记录。换手机、换浏览器、清理 Safari 数据或更换域名时，本地记录不会自动迁移，需要用应用里的“备份和恢复”。
